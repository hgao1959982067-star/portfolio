资产清单与制作说明

文件内容

  • 人物资产：女主角白底四宫格，上排为正面和侧面特写，下排为正面及背面无头全身。
  • 场景资产：开放式居家空间上下双视角，上图斜上方45度，下图正上方俯瞰。
  • 道具资产：产品盒闭合及打开状态、粉剂条包、无把玻璃杯、带把空杯、粉色饮品杯、空陶瓷碗、莓果碗、草莓切片、蓝莓、覆盆子、银勺、粉色圆柱容器、圆环耳饰、花朵项链，共15张独立六格图。
  • 01_整片视频提示词与分镜.md：整片提示词、九段镜头与可编辑口播示例。
  • 02_人物场景道具提示词.md：每项资产的图像提示词。

使用与连续性

  1. 图片是静态创意资产，非三维模型；商品包装各面、饰品和柔性条包的细节需要在制作前锁定。
  2. 产品盒的开合两种图已统一正面 GLOW BERRY 名称与 GB 标记，但盒侧水彩图案、盒内条包外观仍不完全一致；使用时应以确认后的统一包装设计贴图。
  3. 角色的侧面脸型及发型与正面仍可能有差异；全身下装和鞋为造型补充。场景中的厨房远端、家具全貌与地面细节为布景设计补充。
  4. 玻璃杯分为无把、带把和带饮品三个图形状态。成片建议统一使用带把杯进行倒粉、展示和饮用，避免杯把突然出现。
  5. 早餐碗的莓果在不同视角中的具体排列不能保证完全对应。项链柔性链条和勺子的上下视图无法保证为严格的正交六视图，制作时可结合实物或建模修正。
  6. 唯一明确的包装主文案为 GLOW BERRY；其他小字未制作。品牌标记、配料、营养成分、保质期、净含量和其他商品信息均需依据确认的包装文件制作。不要将未确认的功效或冲泡特性作为事实。
  7. 英文口播为可编辑示例。粉末、水、液面和手部动作需检查接触关系，并配合配音和字幕同步完成。
